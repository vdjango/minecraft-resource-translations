# 七牛云多空间接入说明

## 当前实现

镜像仍使用原有公开 URL。云存储只是已缓存文件的一个可选存储位置，不改变翻译服务、下载站发行版或联机节点。默认 **没有空间、所有类别仅本地、暂停新上传**；添加空间后也不会自动搬运历史文件。下载站原有七牛空间仅用于一次 32 字节的独立读写与删除验证，不在本功能中自动复用密钥、路径或发行包。

后台入口是 `/admin/mirror/settings/cloud`，与普通镜像容量和房间临时缓存策略分开。`/admin/mirror` 显示云端副本概况，`/admin/mirror/tasks` 显示云端上传、迁移、失败及重试，`/admin/mirror/resources` 与 `/admin/mirror/temporary` 显示本地/七牛的实际位置。页面的云空间容量数字只统计本站已核验对象，七牛实际账单和整空间用量仍应以七牛控制台为准。

每个七牛空间独立配置：空间标识、Bucket、HTTPS 下载域名、对象根前缀、所在区域的 HTTPS 上传域名、公开/私有、本站托管容量预算和每日上传预算。最多 8 个空间。资源类型逐项指定“仅本地 / 本地 + 七牛副本 / 七牛优先”、目标空间与该空间内的路径：

| 镜像资源 | 客户端临时文件 |
| --- | --- |
| 游戏核心、加载器、模组、Java、依赖库、原版 assets | 模组、资源包、光影 |

“本地 + 七牛副本”上传并校验后保留本地；“七牛优先”上传并校验云对象及下载域名后才尝试释放本地。后台手动提交历史文件迁移，每批最多 200 个；迁移队列持久化，服务重启后可继续。来源仍按镜像下载策略优先重定向，源站不会因配置七牛而抓取整个模组站。临时文件继续遵守房间缓存的默认 8 小时、最长 32 小时，云端临时文件必须使用**私有** Bucket，签名 URL 的有效期不超过当前房间文件剩余保留时间。到期且没有其他房间引用时，源站清理本地与云端对象。

对象键包含独立根前缀、类别路径及 SHA-256；同哈希可由不同房间共用，记录属于镜像或房间的独立索引。上传前验证本地 SHA-256 和大小，上传后验证七牛对象大小及 ETag。七牛下载域名按小流量分散检查；异常时保留本地文件，并让云端跳转回退至原有本地或上游流程。管理员可对每个空间执行查询检查，或显式触发一次 **32 字节上传 → 下载 → 删除**测试。上传失败只影响云端任务，不应中断原有资源下载。

## 凭据与启用顺序

安装镜像进程时包含七牛 SDK：`python -m pip install '.[qiniu]'`。

只在**镜像进程**的环境中设置 `TRANSLATION_QINIU_CREDENTIALS_FILE=/etc/buggcraft-mirror-qiniu.json`，该文件权限限为服务账号可读（例如 `0600`）。文件格式如下，空间标识须与后台一致：

```json
{"space1":{"access_key":"由运维填入","secret_key":"由运维填入"},"space2":{"access_key":"由运维填入","secret_key":"由运维填入"}}
```

后台设置文件与 API **不存储、不返回 AK/SK**。也支持 `TRANSLATION_QINIU_CREDENTIALS` JSON 环境变量，但生产推荐上述独立文件。已有云端对象的空间标识、Bucket、前缀及下载域名禁止在后台原地改指向；新增空间并逐批迁移后再切换类别。多台镜像节点分别配置自己的空间和凭据，禁止假定一台节点的本地缓存已自动复制到另一台。

启用顺序：新增空间并保存 → 配置镜像进程凭据与 SDK → 点击空间的连接检查和 32 字节读写测试 → 设置一类资源为“双副本”并解除暂停 → 观察任务、校验与本地/云端位置 → 必要时切换“七牛优先”并以小批量迁移历史文件。每个空间的本站托管预算只约束本服务记录的对象，不能替代七牛账户级配额；七牛下载带宽、CDN 流量及费用仍需在七牛控制台和现有流量策略中审视。

## 边界与待办

房间文件身份认证仍由既有联机节点签发的授权票据处理；源站验证票据后决定是否接受实体。七牛存储不直接接收玩家写入密钥。早期规划中提及的“公钥轮换”“S3 统一适配器”“七牛费用账单拉取”“跨空间自动迁移”和“按对象计量七牛实际出站流量”尚未实现，不能把后台跟踪容量当成云厂商计费数据。现有多空间分配为**每个类别选一个目标空间**，不是对同一类别自动在多个空间之间按权重分散；空间切换只影响新上传，已验证旧位置继续可读。

七牛 SDK 与私有下载机制依据：[官方 Python SDK](https://developer.qiniu.com/kodo/sdk/python)、[文件信息接口](https://developer.qiniu.com/kodo/1308/stat)、[私有空间下载地址](https://developer.qiniu.com/kodo/kb/1321/how-to-acquire-the-outside-storage-file-links?category=kb)。
