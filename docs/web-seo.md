# 公开页面、索引与首屏

官网和翻译平台保留已有页面风格。公开内容由服务端输出 HTML，Vue 负责交互，不要求搜索引擎先执行 JavaScript 才能读到资源名称、简介和正文。

## 可提交的站点地图

| 站点 | 入口 |
| --- | --- |
| 官网 | `https://bugg.icu/sitemap.xml` |
| 翻译平台 | `https://translate.bugg.icu/sitemap.xml` |

翻译平台的 sitemap 是索引，静态页面和每批 1,000 个项目分别输出。只枚举已收录资源，不生成搜索词、分页游标或任意语言的组合地址。项目详情地址为 `/projects/{provider}/{project_id}`；其他语言可用 `target_language` 查询参数。默认中文地址不带参数。当前导航界面为中文，不宣称已提供完整的多语言网站界面。

公开页面提供独立标题、描述、canonical 和社交分享元数据。未知资源返回真实 404；后台、API 和原始页面模板返回 noindex，搜索结果参数页为 noindex、follow。robots 不屏蔽页面渲染需要的 CSS/JavaScript。镜像项目页重定向主站，避免重复收录。

部署后可以在 Google Search Console、Bing Webmaster Tools、百度搜索资源平台等已验证站点后台提交上述 sitemap。robots 和 sitemap 提供抓取入口，实际收录与排名由各搜索引擎决定。不要通过爬虫 IP 白名单关闭现有安全校验；检查 Cloudflare 的挑战规则是否拦截已验证搜索引擎。

## 状态与已有译文首屏

`GET /v1/projects/{provider}/{project_id}/detail` 一次返回当前原文及简介、正文的可用译文；不调用原站或模型。客户端首次读取时显示“正在读取译文”。只有简介、正文都 ready 且对应当前原文才能标记全部就绪；打开详情发现变化时同步修正列表。

独立详情页的首次 HTML 已包含可用译文，未就绪字段才显示原文。首页将首批目录作为惰性 HTML 数据传给 Vue，避免先出现空白列表再重复请求目录。读取公开 HTML 本身不会申请模型任务；交互页面沿用匿名会话和异步生成流程。

## 缓存与性能边界

- HTML 缓存最多 128 项 / 8 MiB，单项不超过 2 MiB，30 秒过期；数据版本变化立即使旧条目失效。
- HTML 在源站内部缓存，响应使用 no-store，避免 CDN 的长浏览器 TTL 令状态过时；仍提供 ETag，显式条件请求在内容变化后不能复用旧 304。正文 artifact 保持不可变缓存契约。
- JavaScript/CSS 支持浏览器重新验证；文件名含构建哈希的 Vue runtime 可长期缓存。HTML、JSON 及站点资源启用压缩。
- 列表继续分页和批量查询，不装载全部正文；详情仅按需获取。首屏图片保留明确宽高，正文图片延迟加载。

10–20 ms 应作为缓存命中后服务端处理时间的目标，不能作为跨地区公网总耗时保证。测量时分别记录冷启动、预热缓存、响应体大小、并发量和网络位置；不要为了得到好看的数字关闭更新校验。

## 验证

后端测试覆盖无 JavaScript 正文、语言隔离、HTML 清理、sitemap 链接、404、ETag 和原文更新。Vue 测试覆盖详情纠正目录就绪徽标。上线还需检查桌面/移动端实际布局、真实就绪项目是否直接显示译文、模块加载错误，以及搜索引擎 User-Agent 的公开入口状态码。
