# 统一总览与资源清单

统计入口统一为 `/admin`：资源与存储、翻译接口访问、翻译用量与费用使用页内标签切换。移除镜像资源菜单中的“镜像概览”，翻译用量不再在翻译服务菜单重复出现。旧的 `/admin/mirror`、`/admin/traffic`、`/admin/usage` 链接自动打开总览对应标签。

## 数字必须可以找到对应文件

- **资源清单条目**：`inventory.json` 登记的下载地址数量，不是已下载数量，不是云存储文件数。按照游戏核心、素材、Java、库、版本信息、开发映射等具体类型分解。
- **符合自动缓存条件**：与自动任务共用平台和类别筛选规则；排除仅重定向、未选平台、服务端、开发映射和重复压缩格式。符合条件表示可自动补齐，不表示已经完成。
- **镜像本地副本**：普通镜像对象表中仍在服务器磁盘保留的实体；按对象去重。
- **镜像云端副本**：已通过上传核验的存储位置记录，按空间统计；同一实体在两个空间各有一份时计两份。单独列出客户端临时副本，不混入普通镜像。
- 分类表中的**已有副本的条目**是清单下载地址匹配实体的数量；多个地址可能共用同一个对象，因此不等于实体副本数。

点击总览的清单数量或分类进入 `/admin/mirror/sources?view=inventory`，按类型、处理范围、文件名、路径或 SHA1 筛选；每页 50 条。文件详情展示源地址、SHA1、平台、类别策略、自动筛选原因、计划存储空间、当前实际副本和重试原因。

## 功能页面职责

| 入口 | 展示内容 |
| --- | --- |
| 总览 | 资源组成、实际存储、任务状态，以及访问/翻译费用统计 |
| 资源索引 → 资源清单 | 已登记的具体文件、缓存条件和实际位置 |
| 缓存资源 | 已保存的普通副本与客户端临时文件 |
| 自动任务 | 本批进度、正在传输的文件、失败重试与历史；不重复全局存储统计 |
| 镜像设置 | 来源、类别去向、容量和调度配置 |

清单不代表所有平台的完整模组目录。模组、资源包等按需文件保留在对应缓存和映射列表，不伪装成全量游戏清单。统计范围是当前源站，不混算其他部署。

## 实现与开销

总览和统计使用 Vue 组件、Vue Router、Pinia；旧总览的 DOM 控制器不再加载。清单接口 `inventory_files` 经过后台登录和内部控制令牌验证，仅查询已有清单与索引记录，不发起测速、资源下载或云端全桶扫描。清单按文件更新时间缓存解析，分类在线程中计算，分页响应不返回整个清单。资源总览每 30 秒更新，保留旧数据；其他统计按进入、筛选和刷新时读取。
