# 房间文件安全直传与加载器校验

## 玩家上传流程

1. 启动器在本地扫描清单，复用未变化文件的哈希，一次提交路径、大小、SHA-256、SHA-1 和已知下载来源。
2. 源站批量比对公共来源映射、已有镜像文件、房间临时文件和云端副本。已有快速来源直接返回地址，已有缓存直接复用。
3. 对需要补传、去向为私有雨云空间的文件，源站在同一个响应中附带短期预签名 PUT。每次最多预留 32 个文件，直传最多并行 4 个；完成后继续下一批，不为每个文件额外请求上传许可。
4. 玩家直接上传到对象存储 API 的 HTTPS 地址，绕过镜像服务器的上传带宽和中转磁盘。自定义下载域名的 HTTPS 问题不阻塞上传。
5. 启动器通知源站上传完成，源站用自己的凭据读取云端校验结果。只有对象存储返回的 SHA-256 和大小都正确，才写入可下载索引。通知完成是确认文件可用，不是重新上传或重新申请许可。
6. 客户端显示已传字节、总字节、速度与通过校验的文件数；已有公共来源和正常房间下载不等待加速任务完成。

旧启动器不认识直传字段时，继续使用原有源站接收接口；新启动器访问旧源站，会自动恢复旧协议。七牛及未经验证 SHA-256 支持的其他 S3 兼容服务继续使用服务器校验中转。AWS S3 和已实测的雨云支持直传。

## 授权和空间

- AK/SK 永远留在源站；客户端得到的仅是一个指定对象、指定长度、指定 SHA-256 的短期 PUT 地址，不能列目录、读写其他对象或删除文件。
- 云端校验实际文件内容，不信任玩家自行填写的对象元数据。修改字节会被存储服务拒绝；修改签名限制也无法通过验证。
- 预签名地址不是一次性令牌，有效期 10 分钟，重复使用也只能写入相同键和相同内容。不要将地址写入日志或分享给其他人。
- 申请凭证和确认完成都要求有效的房主房间授权，并检查源站 `need` 清单。其他房间或普通成员不能发布这个上传。
- 云端容量和当日上传预算包括未完成上传的预留，和服务器迁移任务使用同一套预算；本地临时容量为 0 不限制云端直传。云空间上传保护开启时不签发新直传凭证。
- 关闭房间后拒绝未完成上传的发布。已经签发的云端 URL 无法立即撤销，预留会保持到过期并预留 2 分钟收尾时间，再清理孤立对象。其他房间仍使用的副本不会被删。
- 直传不成功时回退到原有 SHA-256 校验的服务器接收，接收并行数仍限制为 2。

## NeoForge / Forge 问题

诊断包版本为 `1.0.2-alpha.1`，所选实例 `modpack` 的元数据确实为 Minecraft 1.20.1 / Forge 47.4.20；包内也有此前成功运行 NeoForge 21.1.265 的日志。没有截图中那次失败的完整安装记录，不能仅凭此认定是下载了错误安装器，或仅仅选用了已有 Forge 配置。

本次修复两个已确认的风险点：

1. 早期 NeoForge 1.20.1 使用 `net.neoforged:forge`、`forgeVersion`、`forgeclient` 等兼容名称，原识别遗漏这一格式。识别现在以 Maven group、NeoForge 参数及加载器库为依据，房间、整合包和安装结果复用同一实现。
2. NeoForge 安装后原逻辑在找不到预期文件时随意取包含版本号的第一个 JSON。现在只接受元数据实际识别为 NeoForge 且构建号一致的文件，不能选中同名 Forge/旧配置。

房间校验依然阻止错配启动；错误日志增加房间期望类型/构建号、游戏版本、实际配置标识和识别结果，后续诊断可区分已有配置选择与安装结果错误。

## 验证

雨云真实桶仅使用 39 字节临时探针：错误内容返回 HTTP 400 `XAmzContentChecksumMismatch`；正确内容返回 HTTP 200；HEAD 返回一致的 SHA-256，探针已删除。雨云不会保证 `If-None-Match` 的一次性语义，因此安全性依赖固定对象、签名长度和内容校验，不宣称一次性上传。

自动化检查覆盖：无效/其他房间授权、未上传和校验失败不可用、云端确认后无本地实体即可下载、重复确认不重复计费、房间关闭与凭证过期清理、容量/上传保护，以及客户端不向云空间转发房间 Token、旧源兼容、NeoForge 识别和同名错误配置拒绝。

代码修改不代表旧 EXE 已更新；启动器需重新打包分发才能使用直传与新的加载器识别。

## 来源策略一致性

观察时补充修复：`matched` 仅表示匹配到相同文件，不能单独作为“来源足够快、可以放弃备份”的依据。云端排队与本地释放现在同时检查测量是否已确认、来源可达状态以及当前慢速阈值。调高阈值后已有映射会立即按新阈值保留并安排必要备份，不会继续按旧的快速状态清理实体。

源站已部署安全直传接口，真实雨云的隔离清单 → 预签名上传 → 云端核验 → 下载一致性 → 关房拒绝发布已验证。没有变动联机节点或其他已有服务。
