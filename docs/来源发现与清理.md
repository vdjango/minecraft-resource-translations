# 来源发现与本地副本清理

平台设置的「公开来源」统一管理所有候选来源。新增来源只需填写地址、格式、地区和启停；文件级映射由下载进程后台生成，不占翻译工作线程。

## 自动发现与选择

- 根据本地完整官方元数据清单匹配 Maven / Minecraft 下载路径，核对目标 `.sha1` 与官方 SHA-1；不下载全部二进制。
- Maven 仓库若开放 HTML 目录，可自动遍历目录并发现独有 `.jar`、`.zip`、`.tar.gz`、`.tar.xz`。无目录索引的仓库只匹配已知文件；不能凭根地址获知仓库隐藏内容。
- 对源独有且官方清单未收录的文件，以管理员所添加来源的 SHA-1 为依据，后台显示该来源身份；它不是 Mojang 官方认证。已有官方哈希的同路径文件不能被不同哈希覆盖。
- 支持文件清单 JSON，可列出不在任何其他来源中的文件。文件目标必须与清单同源，清单不超过 4 MiB / 30000 项。
- 每个文件保留多个通过核验的候选。默认国内优先，再按服务器读取校验文件的耗时排序。该耗时不是客户端下载吞吐测量；不同用户网络可能不同。停用、移除或改变来源地址立即从下载候选中排除旧地址。
- 每分钟安排一个增量批次，最多核验 128 个源文件组合，并发 4、每源连接 2；多个源轮流获得扫描机会。每轮每仓库最多读取一页目录，队列与遍历记录各限制 2000 项，文件索引限制 30000 项。目录游标持久化，资源越来越多不会让单个请求遍历全目录。
- 成功核验七天后复查；404 / 不匹配一天后重试；临时错误五分钟后重试。已验证候选最多允许八天旧结果，超过时退出候选。目录遍历完成一天后重新检查，文件清单半小时刷新。下载端仍须校验原始文件哈希。
- 下载请求只查询内存精确索引，健康检查异步执行。已判定异常的源跳过，依次选择同文件其他已核验源，最后按官方路径回退。已经发送给客户端的跳转无法撤回，需要客户端下载重试。

## 添加文件清单

新增来源时选择「文件清单 JSON」，填写例如 `https://downloads.example.org/files.json`：

```json
{
  "files": [
    {
      "path": "/maven/org/example/unique/1.0/unique-1.0.jar",
      "url": "https://downloads.example.org/releases/unique-1.0.jar",
      "sha1": "填写该文件的40位小写SHA1"
    }
  ]
}
```

目标同时提供 `unique-1.0.jar.sha1`（40 位 SHA-1 文本）。公开路径允许 Maven、加载器 Maven、assets、Java、模组与 Mojang 对象下载前缀；不接受管理、翻译 API 路径。必须使用公网 HTTPS，不能同本平台循环跳转、访问私有地址或跳转到其他未登记站点。

手动新增来源后保存，再点击「立即增量扫描」。完整官方清单尚未建立时，可在「存储与同步」扫描清单；来源自己的公开目录 / JSON 可独立发现独有文件。扫描不会抓取整个模组站。

## 覆盖、命中与文件明细

每个源显示已核验文件数、本地副本文件数与逻辑大小、实际下载跳转次数；点击「查看文件」分页列出路径、SHA-1、外部下载地址、本地副本大小和下载命中，每页 50 条。

同一个文件可在多个源覆盖，不能将所有源文件数相加当成唯一文件数。本地逻辑大小也可能包含跨来源重叠；清理预览按物理对象及其引用计算可释放空间。命中次数只统计本服务发出的文件重定向，不代表客户端下载完成，也不包含 CDN 绕过本服务的请求。计数约每分钟写入 SQLite，退出时尽量落盘，意外断电可能丢失未落盘计数。

## 清理已匹配的本地副本

默认保留已有文件。可点击「计算可释放空间」查看匹配数量、最多 20 条样例及按对象去重的空间，再选择「移除已匹配的本地副本」。也可勾选「新来源匹配成功后自动清理」，保存后应用到后续扫描；默认关闭。

清理是后台任务，与清单 / 预下载共用单任务槽。只清理当前直接映射已生效且本地 SHA-1 一致的已校验副本。逐文件重新读取远端校验并 HEAD 检查文件可达和长度；失败立即跳过。删除前再次检查映射未变化及对象未被发送、下载或备份使用。共享对象的其他本地引用保留，最后一个符合条件的引用移除后才删除物理文件、扣减容量。

清理只移除本地副本，不会移除文件映射。之后由外部来源直接提供。预估值和实际释放量可能因并发使用、共享引用、上游临时故障而不同；执行进度在「存储与同步」显示。

Linux 软件包与 Mojang 运行时不是同一个文件。只有路径、哈希与格式实际相符才能映射；不会把发行版 JDK 包替换成 Mojang 指定的 Java 归档。
