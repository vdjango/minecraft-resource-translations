# 资源镜像与共享翻译：需求和实施顺序

更新：2026-10-30。镜像下载与翻译共用网站和导航，下载进程、文件目录、数据库、连接池独立。目标域名 `mirror.bugg.icu`，本地资源存放 `G:\BuggcraftMirror`。公网域名仍需部署配置。

## 统一平台与界面

这是同一个资源服务，包含项目介绍、共享译文、游戏下载和节点协作。工作进程隔离用于保障翻译性能，不对应两套产品或后台。

- 顶部导航统一为「资源服务、开发文档、开发者中心、管理后台」。首页包含项目译文和游戏下载，开发文档统一说明两类接口；开发者中心提供接入、节点目录和部署加入步骤。
- 后台共用管理账户、侧栏和运行概览，同时展示译文生成与下载状态。节点页面按能力展示，译文审批和下载分流保持各自协议。
- 「平台设置」位于 `/admin/settings`，分为翻译服务、下载策略、存储与同步、节点与流量、来源映射、域名与缓存六个页签；只展示选中分类。翻译配置和下载配置分别保存，切换页签保留未保存输入。
- 原 `/mirror`、`/network`、`/admin/model`、`/admin/mirror` 引导至合并后的对应区域；现有 API 路径兼容。
- 模组指 mods 文件，默认不缓存并跳转官方，可配置缓存、备份或重定向；不涉及 AI 模型下载。
- 首次安装访问任意网页自动进入完整初始化向导，先创建管理员，再配置站点、翻译、六类下载和空间、邮件，最后确认开启。进度持久保存，刷新或重启后可登录继续；已有管理员的安装保持原账户与配置。

## 用户需求归纳

1. 六类资源独立管理：游戏核心、加载器、模组、Java、依赖库、原版 assets。模组默认不由本机缓存，不抓取整个模组站。
2. 每类支持本地缓存、仅重定向、备份并重定向、关闭本地服务。备份模式平时由上游发送，已有完整副本在故障后或管理员切换时提供下载。
3. 资源可来自 Mojang、加载器官方站、公共 Maven、Linux 镜像等。只能用路径和内容吻合的文件；不能将另一款 Java 安装包伪装为原清单中的文件。
4. 缓存空间可限制，例如 50 GiB。优先新版本、可保护最新 N 个版本，可改 LRU 或满额停止。资源对象和下载预留共同受限。
5. 默认每 30 分钟增量刷新，跳过未变化签名；文件数量增长不应导致请求遍历磁盘。下载请求使用数据库主键与预维护容量计数。
6. 多站点分担资源流量：按权重、健康、资源类别和节点余量选路；入口通过重定向让客户端直连节点，不中转全部文件。
7. 按本机出口流量和带宽预算尽力服务。接近阈值、磁盘不足、回源失败或下载繁忙时，转健康节点、配置的其他公开源，最后回退官方地址。
8. 其他人既能接入下载，也能部署开源程序加入资源网络；网页明确入口、限制、节点状态与部署步骤。
9. 后台提供 Cloudflare、DNS、HTTPS、缓存规则指南；导航在网站所有页面统一，移动端可用。
10. 先测清单容量，按配置预下载到 G 盘。原版全版本与当前 Java 测量约 54.01 GiB；不能当作 BMCLAPI 全站大小。

## 实施阶段与验收

| 阶段 | 工作 | 验收标准 |
| --- | --- | --- |
| 1：资源基础 | 独立下载、六类策略、容量测量、哈希、Range、配额 | 翻译 API 在镜像离线时可用；错误文件不发布 |
| 2：空间与同步 | 增量刷新、版本优先、保护、LRU、统一导航 | 不变版本不重复读取；保护文件不被旧版本挤掉；计入并发预留 |
| 3：协作与预算 | 健康节点分流、流量预算、带宽准入、外部来源映射、官方兜底 | 达阈值在发送资源前跳转；节点直达路径不循环；Range 按请求长度计费 |
| 4：公开接入 | 接入说明、节点目录、部署和加入步骤 | 公共信息不泄露路径和令牌；管理员明确接纳节点 |
| 5：持续优化 | 自动申请审批、客户端并行测速、跨节点预热、提供商账单对账、原生启动器适配 | 依据真实公网部署与压测逐项验收，不能先宣称已完成 |

阶段 1～4 已实现并通过本地验证；资源节点加入采用管理员明确接纳，尚未上线多个公网节点。阶段 5 为后续演进；已有译文联邦有自己的注册与审批协议，不能把译文节点直接当成资源节点。

## 推荐默认值

核心和加载器缓存；Java、依赖、assets 备份重定向；模组关闭本地服务并回退官方。缓存默认 400 GiB、保留磁盘 100 GiB（后台可改为 50 GiB 等）。优先新版本，保护最新 2 个原版版本；30 分钟刷新。流量与带宽预算未填写时不推测主机套餐，填写后默认到预算 90% 转移，保留突发与其他业务余量。

公开来源改为自动发现：内置阿里云、华为云、南京大学和 Maven Central，可手动添加 Maven、Minecraft 兼容源或文件清单 JSON。每文件校验 SHA-1，保留多个候选，优先国内再按服务端探测耗时排序。扫描按批次增量执行并持久化游标，不进入下载请求链路。后台展示各源已核验文件、本地副本、实际下载跳转次数及分页文件明细。新增源匹配后可预览并清理本地副本，也可开启自动清理（默认关闭）；清理前再次核验校验值、文件可达与大小，跳过在用对象，保留其他共享引用。原 920 条 Central 预设作为首轮扫描前的种子，不再手工导入。

资源路径有效而本机无法提供时回退。未知/非法路径仍为 404，不提供任意 URL 代理。第三方源须管理员主动配置，其服务范围、路径和使用政策由接入方核对；不会默认将公共站点当作我们可无限使用的节点。

## 可复用的公开来源调研

| 来源 | 可以用来做什么 | 限制 |
| --- | --- | --- |
| [Maven Central](https://maven.apache.org/guides/introduction/introduction-to-repositories.html) | 相同 Maven 坐标、相同版本的依赖库 | Mojang 专有库和加载器专有库不一定存在；须保留官方 SHA-1 验证 |
| [SJTUG Maven 镜像](https://mirror.sjtu.edu.cn/docs/maven-central) | 该站文档明确提供 Central 反向代理，说明 Linux 镜像站也能提供 Java 依赖 | 不等于支持整个 Mojang libraries；只有已验证匹配的路径才能配置回退 |
| [Adoptium Linux 软件包](https://adoptium.net/installation/linux) | Debian/Ubuntu、RPM、APK 安装 Temurin；适合独立的 Java 获取入口 | DEB/RPM、不同发行版 JRE 与 Mojang runtime 清单不是相同文件，不作透明替换 |
| Mojang 与加载器各自官方站 | 默认准确的最终来源 | 实际速度随运营商、地区和时段变化；本机短采样不代表所有用户 |

备份切换只能覆盖已保存且未淘汰的文件；已经发给客户端的重定向无法由服务端撤回。故障探测完成后新请求生效，旧请求需重试镜像地址。健康检查和准入预算均不是运营商级 QoS 或 CDN 全链路的无限带宽保证。
