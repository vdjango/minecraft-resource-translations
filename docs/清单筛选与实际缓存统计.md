# 清单筛选与实际缓存统计

“清单筛选 24006 / 24006 条”表示逐条检查了资源索引中的 24006 个下载条目，不表示下载或上传了 24006 个文件。索引包括仅重定向资源、未选择的平台、服务端文件、开发映射与重复压缩格式。保留索引和公开来源映射不需要保留文件实体。

自动任务按当前策略将条目归为已有副本、安排下载、等待重试和跳过原因。各项统计按本轮累积；“安排下载”也不代表已经写入云端。重启后会接续，旧版本统计缺少分类时重新执行一轮索引检查，不会重新下载已存在的有效副本。

实际占用分开查看：

- 本地副本：服务器实际保留的对象，不包含仅云端对象。
- 云端副本记录：已通过上传核验且仍在对象位置索引中的对象；任务历史的完成次数不能代替此数。云空间管理面板和存储服务端的对象列表是实体数量的直接依据。
- 房间上传的临时文件：独立的授权、有效期和清理范围，普通镜像缓存清理不能顺带删除。

2026-11-04 排查时，主源清单共 24006 条，按当时配置，2303 条符合自动缓存条件；其余 16527 条仅重定向、1235 条平台不符、1058 条服务端文件、732 条开发映射、2151 条重复压缩文件。云端索引有 2308 个普通对象（2114556503 字节）和 3 个临时对象（2109417 字节）；普通上传任务均已完成。对雨云普通、临时对象各抽查一个 HEAD，均存在且大小一致。此处为当时快照，非固定数量承诺。

此前维护脚本清理的是普通镜像的本地实体、已登记的普通云端对象及其缓存、任务记录，保留了来源映射、资源索引和临时文件。自动同步随后按类别策略重新准备文件。不能把“普通缓存清理”描述成“全部数据清空”，也不能为修正页面数字再次删除有效文件。
