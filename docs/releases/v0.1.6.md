# 资源源站 0.1.6

正式版本，包含源站后台接入流程和资源管理改进。

- 在「系统设置 → 镜像设置 → 客户端加速」增加「接入联机节点」入口，与「节点管理 → 接入节点」共用邀请窗口。
- 输入节点名称后生成一次性接入邀请；邀请有效期 10 分钟，仅可领取一次。
- 联机节点领取邀请时自动生成并保存授权密钥，无需手工生成或复制长期密钥。
- 窗口说明联机节点的填写路径，并可直接前往节点管理查看及撤销授权。
- 重新生成邀请前清除旧邀请，生成失败时不会误用旧内容。
- 收录现有的统一资源后台、存储管理、下载来源与客户端文件加速改进。
- 正式发布须通过前端检查、后端回归及 Linux / Windows 打包。

接入路径：源站生成邀请 → 联机节点后台的「节点设置 → 资源下载加速」粘贴 → 接入源站。联邦内新加入节点由联机节点 0.3.9 自动采用邀请方配置。
