# 雨云对象存储与自动 HTTPS

下载域名：`https://s3oss.bugg.icu`。Bucket：`bugg`，API：`https://cn-nb1.rains3.com`。默认准备 80 GB 容量、400 GB 每月下载预算，90%（360 GB）起分流，上传每天 1 GB；初次接入保持新上传暂停、各类别仅本地，不迁移现有文件。

## 后台位置

**镜像设置 → 存储与容量**（`/admin/mirror/settings/cloud`）：所有本地/云端容量设置、雨云/七牛/通用 S3 空间、按类别选择空间、流量预算、凭据可用性、证书状态和轻量验证。**同步调度**只设置下载并发、刷新周期；**资源管理 → 同步任务**展示上传进度、失败原因、逐项重试、分批迁移。资源列表展示本地及云端位置。

核心、加载器、模组、Java、依赖库、原版资源、客户端模组/资源包/光影分别选空间和路径。新增空间不会改变原有类别缓存/重定向策略，也不会下载原本只重定向的文件。多个雨云或七牛空间可并存；更换类别目标只影响新上传，旧位置继续可读。

### 容量与配置口径

| 设置 | 作用范围 | 云端优先时 |
| --- | --- | --- |
| 普通镜像本地容量上限 | 普通镜像的本地副本与下载预留 | 上传前仍需临时落盘；已释放的云端文件不占此配额 |
| 房间临时文件本地容量上限 | 房间文件的本地副本与上传预留 | 独立于普通镜像配额，不统计已释放的云端文件 |
| 磁盘至少保留 | 两类本地文件共用的磁盘保护线 | 继续生效，保护系统、数据库和临时落盘 |
| 每个云空间的托管容量 | 该空间中本站跟踪的已核验云端对象 | 独立计算，不受本地缓存上限约束 |
| 每个云空间的月下载预算 | 该空间签发下载链接的预留流量 | 达到阈值后分流 |
| 本地清理策略、保护版本 | 普通镜像本地副本 | 不删除云端对象 |
| 下载并发、清单刷新周期 | 回源下载与发现新版本 | 继续生效，与云存储上传队列分开 |

容量设置集中在一页；客户端缓存策略页仅显示容量摘要并链接回来，不再提供第二个容量输入框。先选择“本地存储”或具体空间，再选本地副本策略，避免出现“云端模式却没有目标空间”的无效组合。空间可添加名称，多个雨云、七牛和 S3 空间按类别自由搭配，最多 64 个；房间临时文件仍须选择私有空间。

存储页使用 Vue/Pinia 独立表单，只提交存储相关字段。后台合并其他配置；仅修改云端配置不会触发本地缓存清理。保存失败返回具体类别及原因，保留未保存编辑，自动刷新不会覆盖编辑内容。此轮已验证类别选择、保存后刷新恢复，以及在同步调度间切换。

## 服务端凭据

安装 `pip install '.[s3,acme]'`。用 `TRANSLATION_CLOUD_CREDENTIALS_FILE` 指向服务器上的私有 JSON 文件（服务用户可读、权限 0600），以空间标识为键。兼容旧 `TRANSLATION_QINIU_CREDENTIALS_FILE`。

```json
{
  "rainyun1": {
    "access_key": "从雨云对象存储面板取得",
    "secret_key": "从雨云对象存储面板取得",
    "rainyun_api_key": "从雨云账户 API 密钥取得",
    "rainyun_bucket_id": 12345,
    "cloudflare_api_token": "所属区域 DNS 编辑 Token"
  }
}
```

示例中的 Bucket ID 必须换成自己的。缺省时尝试从雨云桶列表匹配名称。S3 AK/SK 只操作文件；部署证书需额外的雨云账户 API Key。密钥不存镜像设置，不下发浏览器，不返回后台 API。

## 免费证书自动维护

1. 下载域名的 CNAME 指向雨云要求的地址，保持私有桶。Cloudflare Token 需所属区域 DNS 编辑权限。平台使用 DNS-01，不占 HTTP/HTTPS 服务端口。
2. 后台保存空间，开启“自动申请、续期并部署免费 HTTPS 证书”，或手动点击“申请 / 检查证书”。操作立即入队，浏览器不等待签发。
3. 后台 Certbot 申请 Let's Encrypt 免费证书；约每 12 小时错开检查，Certbot 在续期窗口内更新。申请失败保留旧证书，下次检查重试；私有诊断日志位于 `mirror_root/cloud-tls/<空间>/logs/`。
4. 成功后通过雨云账户 API 上传证书到 SSL 中心，并仅为该 Bucket 补充域名及启用 HTTPS。SSL 中心自动匹配域名证书。平台随后验证真实下载域名的证书和有效期，验证成功才显示已部署。
5. 证书私钥仅在服务端私有目录和雨云证书中心。DNS 临时凭据文件在任务结束清理。维护进程与文件上传暂停开关独立，服务重启后恢复定期检查。

没有账户 API Key 或 DNS 权限时显示“待配置”，不会假装已启用 HTTPS，也不会修改其他域名、联机节点或网站证书。建议仅由主镜像维护同一域名证书，其他节点关闭自动维护，避免重复签发。

实际联调发现：雨云部分接口对 API Key 返回 `403 / 30093：该接口未对 API Key 开放`，SSL 中心接口也可能返回 `403 / 10005：无访问权限`。平台区分“已签发”和“已部署”；签发成功但部署被拒绝时显示“等待部署”，管理员可从本页下载含私钥的证书包，在雨云 SSL 中心导入。证书包接口必须管理员会话，响应禁止缓存。此状态不能称为雨云端自动部署已完成。DNS Token 若只有 30 天有效期，应在到期前更换，否则后续续期会失败。

## 文件与流量保护

上传前核验本地 SHA-256；上传后核对远端大小、SHA-256 元信息及 ETag，再检查真实下载 URL。私有 S3 下载对实际域名签名，支持断点 Range 和 HEAD。域名须绑定到 Bucket，路径为 `/对象路径`；API Endpoint 下载使用 `/Bucket/对象路径`。

容量预算只包含本站跟踪的已验证对象，不扫描或删除桶内其他文件。单个大文件失败不会阻塞后面的上传任务。本地副本只在云端校验可读后按类别释放；配置流量上限的房间临时文件保留本地兜底。

月下载预算采用北京时间自然月，按本站签发下载重定向时的完整文件大小保守预留；HEAD 和存在性查询不扣预算。达到阈值即尝试其他云端位置、本地或现有上游，正在下载的文件不会被取消。签名链接重复使用、外部入口访问和服务商非自然月计费周期不能由此精确计量，实际用量以雨云账单为准。若多个节点共用套餐，分别分配预算，合计不超限；本次只在主站配置此空间。
