# 镜像后台重设计与自动重建

## 页面约定

参考 Ant Design 的 Layout、PageContainer、Table：固定平台头部与一级分组侧栏；内容区只有标题、必要指标、一个主要工作区。列表分页，行详情在侧栏展开；说明放在帮助中，不再堆放流程讲解卡片。

| 页面 | 默认内容 | 次级内容 |
| --- | --- | --- |
| 镜像概览 | 实际本地/云端占用、登记数量、待处理任务 | 自动流程入口与当前状态 |
| 缓存资源 | 标签：镜像副本 / 房间临时文件 | 分类分页、实际位置、到期时间；详情侧栏 |
| 资源索引 | 标签：扫描覆盖 / 仓库映射 / 模组映射 / 来源质量 | 覆盖计数与下载命中分开，已登记数量与实际占用分开 |
| 自动任务 | 标签：资源回源 / 云端迁移 | 各自切换当前、异常、最近记录；不提供扫描、预下载、重试、停止按钮 |
| 下载来源 | 六类资源策略表，选择一类再编辑 | 来源仓库、采样设置，分别切换 |
| 存储与容量 | 存储空间列表，选择一个再编辑 | 本地容量、房间存储、链接设置，分别切换 |
| 同步与分流 | 自动同步周期、平台范围 | 本机分流，云端类别不参与本机出口限额 |
| 房间文件 | 启用、期限、单文件限制 | 节点授权；匹配记录移到资源观察区 |
| 域名 CDN | 公开地址及三条规则入口 | 一次查看一条规则，复制表达式 |

设置页的未保存状态保留，列表轮询不覆盖表单。使用 Vue Router 查询参数保存当前分区；表单及列表使用 Pinia 状态，不再由镜像页 DOM 控制器生成。

同步、映射、扫描属于同一资源供应流程，但执行观察与索引结果不同：结果集中到“资源索引”，执行集中到“自动任务”。二者互相链接，配置只在系统设置修改。旧地址自动跳到合并后的对应标签；固定菜单不随列表刷新重建。

## 自动运行

清单登记不等于实体缓存。自动预下载只处理启用的类别与平台；默认不下载服务端、开发映射、Java LZMA 重复压缩副本。按需下载仍可访问完整清单。

保存设置后自动重新核对。已有清单分批补齐，清空实体后也能重建，不能只检查清单变化。已完成文件和健康外部映射跳过；失败单独排队，指数退避和随机错峰，不占住后续文件。404 保留具体地址错误并降低重试频率；重试时复用其他来源兜底。

普通回源失败、云上传失败、等待配置、等待容量分别显示原因和下次检查时间。达到配额时进入等待，不反复下载、删除、再下载同一批文件。

## 本次清空范围

清理两台镜像服务自己的普通缓存实体及对应云端对象、旧上传任务和失败队列；仅删除缓存索引中登记的对象键，不清空整个 Bucket。保留配置、凭据、公开来源映射、质量历史、翻译数据库及联机服务。有效房间临时文件继续按既定租期清理，避免中断正在使用的共享文件。

执行前记录本地和云端数量并备份索引与配置。清理后由新自动调度按现有类别和存储去向重建，不扩大到未启用类别。

## 验收

只做本次功能相关检查：自动补齐、退避/恢复、平台与文件用途筛选；Vue 构建与路由/登录/保存；桌面和窄屏检查溢出、列表和详情面板；线上核对清空结果与自动任务状态。

参考：[Ant Design Layout](https://ant.design/components/layout/)、[PageContainer](https://v4-pro.ant.design/docs/layout/)、[Table](https://ant.design/components/table/)。
