# 对象存储与七牛云接入规划

本阶段为接入规划，不启用七牛上传、不产生云存储费用。后台的资源观察、同步任务与设置按照本文件预留扩展位置，与 [后台信息架构与资源观察台](后台信息架构与资源观察台.md) 共同实施。

## 接入后保持稳定的内容

启动器继续使用平台原来的资源 URL、文件哈希和房间文件协议，不感知文件位于本地或 Kodo。上传计划继续先接收文件信息、优先选择可用公开来源，只在确有需要时请求实体。节点负责房间身份和授权，源站负责决策、校验与存储，云存储不接收节点长期身份凭据。

## 数据和存储适配层

业务索引保留 `resource_id / sha256 / sha1 / size / category / source_urls`；对象位置独立保存为 `object_locations(digest, backend_id, object_key, state, verified_at, last_error)`。一个哈希允许同时有本地和七牛副本，资源记录不因迁移而重建。不能将 URL 当作唯一身份，也不能将临时签名 URL 写成持久来源。

存储后端统一提供 `stat`、`put_verified`、`open_range`、`download_url`、`delete`，返回存在性、字节数和校验元数据。本地适配器先保持现有原子落盘语义；七牛优先使用官方 SDK，S3 兼容方式作为另一种适配器，不假定两者签名、域名和功能完全相同。大文件通过工作队列处理，不在 API 请求中等待搬运。

对象键使用独立前缀：`mirror/sha256/前两位/完整哈希` 和 `room/sha256/前两位/完整哈希`。两类容量、生命周期和费用预算独立；房间引用和期限留在业务索引，多个房间共用一份对象。源站依然计算 SHA-256/SHA-1，七牛 ETag 不作为这两个哈希的替代品。

## 后台菜单与展示

- 「设置配置 → 镜像设置 → 存储与调度」增加存储后端管理入口：本地目录、Kodo 区域、空间、对象前缀、下载域名、访问方式、容量/流量预算、失败回退、凭据引用。密钥只存在服务器密钥配置中，页面只显示是否配置和最后验证结果。
- 「资源与任务 → 缓存资源 / 客户端临时缓存」增加存储位置筛选和副本详情，区分本地/七牛/迁移中/校验失败/待删除，分别显示物理占用与逻辑资源数。
- 「资源与任务 → 同步任务」接入上传、迁移、核验、清理队列，展示已完成文件/字节、速度、错误与重试。不会把迁移上传伪装成官方源同步。
- 「镜像概览」展示本地磁盘、七牛对象容量、上传流量、下载分发流量和费用估算，统计有明确时间范围。平台计量与七牛实际账单分开。

## 无缝迁移与回退

1. 后端连通性、上传/下载/Range、权限及校验验证通过后，新增文件可按策略写入七牛；已有文件继续本地读取。
2. 管理员创建迁移任务，按分类/年龄/容量筛选，限制并发与每日迁移流量；上传后验证对象大小及校验元数据，再标记云副本可用。
3. 读取顺序由策略选择，保持平台入口不变，可返回七牛自定义下载域名或短期签名重定向；签名有效期覆盖下载与续传需要。私有链接、带鉴权的响应按缓存规则处理，不共享缓存管理凭据。
4. 只有云副本核验成功、没有活跃读写、没有未完成引用，且管理员选择释放本地空间时，才删除本地副本。云不可用时优先本地副本，其次已核验公开来源或其他健康镜像。
5. 迁移任务可暂停、继续、失败重试；保存清单与检查点，恢复时只补缺失对象。回滚仅切换读取与写入策略，不删除已验证资源。

## 临时缓存与生命周期

默认 8 小时、最大 32 小时仍只作用于客户端临时缓存。业务调度器依据所有有效房间引用的最晚到期时间决定删除，云生命周期只是兜底清理，不能假定按小时精确执行；不得用整空间的粗粒度到期规则误删普通镜像资源。到期请求先回到源站决策，不将失效云签名交给启动器。短期签名仍可能在有效期内访问，清理与访问有效期需要共同设计。

下载站发行版、节点玩家日志、翻译数据库、模型密钥不自动迁移进镜像存储。七牛测试域名不作为长期生产地址，正式接入时验证自有下载域名、区域与访问策略。

## 接入验证范围

确认不改客户端 URL 协议；相同哈希并发上传去重；坏文件不发布；Range/HEAD/重定向和私有签名有效；迁移暂停恢复不重复传；云故障可回退；删除遵守活跃引用与文件保护；分别核对本地与云端空间。完成这些后逐步切换，先少量对象，再扩大范围。
