# 镜像质量与网站体验

实施日期：2026-11-01。镜像是平台主要能力，译文为配套服务；统一网站、账户和后台，镜像使用独立管理菜单。

## 页面体验与 SEO

- 官网、下载站、联机节点、译文和镜像统一使用首屏加载反馈、内容骨架与点击即响应的导航过渡。
- 同站 Vue 页面支持无需整页刷新的导航、前进后退、取消旧请求；跨站保留正常链接并立即反馈。下载、授权回调、表单和新窗口链接保持原有语义。
- 保留服务端 HTML、标题、canonical、结构化数据和 sitemap，供搜索引擎及无 JavaScript 用户读取。管理、搜索参数和 API 不作为索引入口。
- 快速响应不强加等待动画；慢请求显示状态和重试入口；支持减少动画的系统设置。

## 来源质量

评估单位是“本资源节点 → 来源”，不能把服务器测速宣传成所有玩家的真实下载速度。HTTP 重定向完成后的用户下载不经过本站，本站无法直接测量；后台明确标注观测位置和采样方式。

- 记录首字节、有限范围实际下载吞吐、失败类型、采样字节、时间、样本量、覆盖天数和近期趋势；HEAD 只用于连通性，不当作测速。
- 使用已发现、哈希一致的真实文件，随机轮换文件。404 表示该文件缺失，不自动判定整个来源网络差。
- 默认每次仅测一个来源的一个文件，256 KiB 采样、10 秒超时、总计每天 32 MiB；每来源 6 小时左右并加随机抖动，全局至少间隔 2–5 分钟。失败退避，不启动时全量测速。
- 保存 30 天历史，使用近 7 天统计；至少 8 个有效样本、跨 3 天才能评为稳定。优秀要求成功率至少 98% 且平均实际下载速率不低于 2 MiB/s；良好至少 90% 且不低于 512 KiB/s；其余为待改善。样本不足/长期无样本单独显示，不伪装为稳定。
- 优秀来源优先重定向；慢/波动来源的文件优先本地缓存。多来源覆盖同文件时综合选择最佳来源，不能因为某个差来源就重复缓存。
- 后台按来源查看覆盖文件、命中、本地占用、质量指标和最近样本，可立即安排一次受预算约束的测速或禁用来源。默认不自动删除来源。
- 来源地址或仓库类型改变后重新开始观察；超过两天没有新样本显示过期，不继续据此新增缓存。

## 缓存与调度

- 六类资源策略始终优先：纯重定向、关闭不被质量评分自动升级成缓存；备份模式仍然先跳转，后台备份。
- 新增质量自适应开关：来源稳定且快速时节省本地空间；达到观察门槛后上游慢/不稳定的文件进入本地缓存/备份候选。
- 版本优先和 LRU 继续负责空间淘汰；质量影响是否新增缓存、预下载顺序和来源命中后的清理保护，不突破容量、剩余磁盘、类别开关和并发限制。质量参与空间淘汰排序留待后续按实际命中收益调整。
- 无可信副本时不因低评分拒绝下载，继续回退其他来源/官方。质量建议清理不能替代删除前的文件哈希和可达性检查。
- 后续阶段：按玩家区域可选上报匿名传输结果、联邦节点签名交换观测、按资源热度和单位空间收益细化排序。无数据前不宣称已实现全球最优调度。

## 模型费用

- 内置 OpenAI 官方标准 GPT 文本价格表，记录核对日期及官方来源；按输入、缓存输入和输出分别计算美元参考费用。
- 支持模型快照别名、用户自定义供应商价格覆盖、每条调用价格快照。没有缓存明细时按未缓存计价并标为参考估算；没有 token 用量时保留未知，不能填零。
- 已收录模型的缓存写入按对应官方价格计算；已核实的 GPT-6.1-sol、GPT-6-sol 长上下文附加费用按官方规则计入。推理 token 已包含在输出中，不重复计费。
- 历史保留原始可用用量，已有价格快照不被新价格覆盖；不能恢复的旧用量明确标注。后台显示估算依据和未知记录数量。

## 与房间文件补齐任务的接口边界

房间任务负责客户端补齐队列、来源元信息提交及临时文件缓存。本任务提供通用的 `SourceQuality` 长期质量记录、后台质量页和普通镜像缓存策略；两个任务合并时复用这些记录，玩家下载请求不触发同步测速。

建议由联机节点认证房主和成员，签发短期、限定房间和文件哈希范围的凭证。源站验证凭证后接收文件元信息，优先返回可重定向来源，仅列出确实需要上传实体的文件；实体传输必须核对哈希和大小。源站不自行建立另一套房间账户体系。

房间客户端临时缓存默认保留 8 小时、最长 32 小时，采用独立空间上限和慢速阈值（例如 100 KiB/s）；普通游戏、加载器、依赖等缓存继续使用各自策略。临时缓存尽量避免落盘，未知质量不能直接等同慢源。后台新样本只影响后续决策，不能中途取消用户下载或删除正在使用的文件。此节是跨任务接口约定建议，具体授权、上传计划和临时缓存由房间任务实现。
