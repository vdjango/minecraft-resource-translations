分发与安全边界

节点先申请，管理员验证地址所有权后启用。客户端通过实际往返测速选择节点；节点离线或被撤销后退出发现列表，读取失败自动回主服务。

镜像只缓存公共译文与项目介绍，不持有主服务模型密钥、管理令牌或启动器应用密钥。申请翻译、任务票据和其他写入始终发送主服务。

节点上报数字单独显示，主服务回源请求不与节点请求相加冒充独立用户。节点异常时撤销即可停止分发。
