节点与流量

配置协作节点、分流权重与本机出口预算。

一个入口，多个下载站点。

每行填写 HTTPS 站点与权重，例如 https://mirror-2.example.com 2。停用节点可删除该行。仅缓存模式参与分流；备份模式平时直接访问官方。

每 20 秒检查节点状态，失败节点退出分流。节点使用同一程序、独立磁盘与配额；文件名和校验值一致，互不共享管理凭据。节点下载路径防止循环跳转。

把流量留在预算之内。

按接受的文件 / Range 长度提前计入；取消和条件请求可能保守多计。这里只统计本机资源响应，不含翻译、回源、CDN 账单；带宽是准入规划，精确限速与运营商计费需配合代理或主机系统。

    SOURCE INTELLIGENCE

    让长期表现决定资源去向

    稳定快速的来源优先直连；有需求且上游表现不佳的文件，优先保留本地副本。

    轻量采样计划

    每批仅测一个已核验文件，读取有限数据；间隔随机错开，失败退避，达到每日预算即暂停。结果表示本节点到来源的表现，不能代表用户重定向后的下载速度。

    默认每个来源约 6 小时，随机浮动 25%；全站每 2–5 分钟最多一项，单次 256 KiB、10 秒超时，每天最多 32 MiB。手动采样同样排队并受预算限制。

    至少 8 次有效观测、跨 3 天、含 3 次文件传输才评级：优 ≥98% 可用且达到快速参考；良 ≥90% 可用且高于慢速参考；其余为待优化。文件 404 单独记录，不算整站故障。停测超过两天显示“已过期”。

    CLOUDFLARE SETUP

    Cloudflare 与域名配置指南

    目标域名 mirror.bugg.icu。翻译平台的原域名继续可用，先检查新域名的 HTTPS、回源与下载，再切换启动器。

    1. DNS 与 HTTPS

    公网服务器添加 mirror 的 A / AAAA 记录，开启橙云代理；SSL/TLS 使用 Full (strict)，源站安装有效证书。只有 IPv6 可达时不要添加无效 A 记录。本地电脑可通过 Cloudflare Tunnel 接入，无需暴露磁盘或管理端口。

    本地 Tunnel 分流：/assets/ 下的脚本、样式、图标去 18448；/assets/两位哈希/完整SHA-1 去 18449；/java、/mods、/maven、/v1/packages、/v1/objects、/v1/products/java-runtime 及加载器路径去 18449，其余去 18448。完整示例见仓库 deploy/cloudflared-mirror.yml。

    2. 给二进制和无扩展名资源启用缓存

    Cloudflare → Caching → Cache Rules → 创建规则。只匹配镜像资源路径，缓存资格设为 Eligible for cache，边缘 TTL 和浏览器 TTL 遵循源站 Cache-Control，不强制覆盖错误响应。无扩展名 assets 与 JSON 不会全部默认缓存。

    带内容哈希的游戏与资源：一年 immutable；可变 JSON / XML 与加载器目录：五分钟。以上仅适用于缓存模式；官方重定向返回 307 + no-store，Cloudflare 不应缓存跳转。切换策略后，先前的 CDN 文件可能仍在有效期内，需要立即生效时清除对应路径的 CDN 缓存。
    

    3. 最后一条规则：管理与翻译接口绕过缓存
    将下列规则放在缓存规则之后，动作为 Bypass cache；后面的规则可能覆盖前面的设置。不要使用全站 Cache Everything。
    管理页面、管理 Cookie、带 Authorization 的请求与翻译 API 都绕过缓存；不缓存后台操作和登录返回。保持翻译 SSE 的代理缓冲关闭。
    

    4. 检查缓存命中与续传
    curl.exe -I https://mirror.bugg.icu/mc/game/version_manifest_v2.json
curl.exe -I https://mirror.bugg.icu/assets/前两位/完整SHA-1
curl.exe -I -H "Range: bytes=0-1023" https://mirror.bugg.icu/某个已缓存文件
    同一资源重复访问后检查 CF-Cache-Status: HIT、Age 与 Cache-Control。Range 应返回 206 和正确 Content-Range。Free / Pro / Business 单文件缓存上限为 512 MB；Enterprise 默认 5 GB。超过上限可直连独立下载域名或使用合适的对象存储方案，不能依靠 Range 把整文件变成可缓存文件。
    Cloudflare 缓存会被逐出，不是备份；本地文件才是持久副本。大规模分发部署前核对所选产品当前适用条款与容量。
