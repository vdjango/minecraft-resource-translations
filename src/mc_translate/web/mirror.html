02 / HOST

部署自己的资源节点

克隆开源项目，安装 Python 依赖，启动独立资源进程。配置自己的 HTTPS 域名、六类策略、缓存空间与出口预算。

python -m mc_translate.mirror

仓库 deploy/resource-node.example.json 和 docs/资源节点部署.md 提供配置。资源节点不需要翻译模型密钥。
