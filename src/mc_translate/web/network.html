HOW TO JOIN

用一台服务器，加入共享译文网络。

01

准备服务器与域名

准备可用的 Docker 环境，将自己的域名解析到服务器，并配置 HTTPS。节点只需存储缓存，不需要主服务的模型 API Key。

02

配置镜像模式并启动

按照 README 的“加入共享网络”配置公开地址、节点名称、区域和联系方式。启动后自动向主服务申请，节点凭据保存在自己的数据卷。

03

审批通过后自动分流

管理员验证节点后批准；节点心跳更新后进入可用列表。用户测速选路，节点缓存命中直接返回，未命中合并回源。

每个节点负责什么

社区镜像共享的是译文读取和缓存。翻译生成、额度、密钥申请与管理由主服务负责，避免多个节点重复生成或泄露私密信息。你也可以不加入网络，独立配置自己的模型服务运行完整平台。

缓存正文按 SHA-256 校验并限制磁盘容量。动态译文状态采用短缓存；离线节点停止分发，无法读取时客户端自动回退，不将过期状态伪装成最新译文。
